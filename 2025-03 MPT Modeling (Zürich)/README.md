# Workshop on Multinomial-Processing-Tree (MPT) Modelling

* Lecturer: Daniel W. Heck (University of Marburg)
* Date: 20.3 and 21.3.2025, 9h - 17h
* Location: University of Zürich (UZH) 

### Abstract

Multinomial processing tree (MPT) models provide a powerful tool for disentangling different cognitive processes contributing to the same observable responses. In many fields of psychology such as memory, decision making, and social cognition, MPT models have been successfully used to test hypotheses concerning specific processes via separate model parameters. The workshop covers the basics and the most recent developments in MPT modeling. Participants will practice how to develop their own MPT models, how to assess model fit, how to test hypotheses on model parameters, how to check for identifiability, and how to select the best model from a set of candidate models. The workshop also provides an introduction to hierarchical Bayesian MPT modeling with the R package TreeBUGS and gives an overview of approaches for modelling categorical and continuous data jointly.
